# SAILCRAFT — Sailmaking Website

A responsive, editorial-style landing page concept for an independent sailmaker based in Latvia.

## Overview

The website introduces the sailmaking services, presents reference imagery, and provides a contact section with a message form.

### Sections

- **Hero** — opening statement and visual identity.
- **About** — introduction to the independent sailmaking practice.
- **Services** — custom sailmaking, sail resizing, and sail repairs.
- **Our Work** — an image gallery using temporary reference imagery.
- **Contact** — phone, email, and enquiry form.

## Built with

- HTML5
- CSS3
- Vanilla JavaScript
- GSAP and ScrollTrigger (loaded from CDN)
- Google Fonts

## Run locally

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` with the Live Server extension, or serve the folder with any local static web server.

## Publish with GitHub Pages

1. Open **Settings → Pages** in the repository.
2. Under **Build and deployment**, select **Deploy from a branch**.
3. Select branch `main` and folder `/(root)`.
4. Save and wait for the deployment to finish.

## Contact form setup

The contact form currently uses FormSubmit's AJAX endpoint and is configured for `example@gmail.com`.

- Replace `example@gmail.com` in `index.html` and `script.js` with the sailmaker's confirmed business email before launch.
- The recipient address must be activated with FormSubmit before submissions can be delivered.
- Test the form after activation and before sharing the live website with customers.

## Images and content

Some photos are temporary reference images loaded from external image providers. They are illustrative and are not represented as verified photographs of the sailmaker's own projects. Replace them with original project and workshop photos when available, and confirm commercial-use permissions for all third-party images before public business use.

Contact details in the current concept are placeholders supplied for the draft website. Confirm them with the business owner before launch.
